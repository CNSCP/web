CNS/CP Licensing

Five things, each with its own terms, all of them serving one end: a single Connection Profile namespace, so that every implementation means the same thing by a name.

Why there is one namespace

CNS/CP works the way DNS works: a name means one thing because there is one place it is registered. Everything on this page is arranged to keep that true. The specification, the software and the Profiles are open so that anyone can implement; the patent commitment and the name are conditioned on conformance so that what calls itself CNS/CP resolves the same names the same way.

The specification

The CNS/CP specification was developed by Padi, Inc., which holds the intellectual property in it. It is published openly at github.com/CNSCP/specification, and it is being contributed for development as an open standard under a recognized standards body, whose publication terms will govern the standard once issued. Until then the published draft may be read, cited and implemented freely.

The patent commitment

Padi has committed to license its essential patent claims on a royalty-free basis for implementations that conform to the specification’s conformance clause. That commitment is made in Padi’s declaration to the standards body, and its scope is set there rather than in any software licence. Conformance is defined by the specification itself.

The software

Software published by the CNSCP organization on GitHub — including the reference Registry — is licensed under the Apache License, Version 2.0, unmodified. Nothing is appended to it and nothing is conditioned on it.

The Connection Profiles

Every Profile published to the CP Registry is licensed by its publisher to everyone under Creative Commons Attribution 4.0. Those terms are set by the Registry’s terms of publication, not by the software licence. The licence carries the Profile, not the name: an adaptation is a new Profile, and a name is registered under its Prefix holder.

The name

CNS/CP™ is a trademark. The name may be used to describe an implementation that conforms to the specification’s conformance clause; it may not be used for one that does not. A usage policy setting out the terms will be published here. The mark, like the Registry, is held today by Padi, Inc. and is intended to pass to the organization that will govern the Registry.

What this page does not cover

Padi’s own products and services built on CNS/CP are licensed by Padi on their own terms and are not part of any grant described here. Nothing above is needed to use them, and nothing above is affected by them.
