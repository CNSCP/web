About the CNS/CP Project

CNS/CP centers every digital relationship on explicit capabilities, roles, and use-case context — not merely on where a node is, but on what a node provides, and for whom, within a particular real-world or logical context.

Connection Profiles

Every connection in CNS/CP is defined by a Connection Profile — named in the format cp:profile.example — that describes both the consumer and provider roles involved. Each declared CP outlines the properties expected of both roles, allowing system nodes to advertise or request capabilities universally.

Nodes declare their intended profiles and the context where their capabilities apply — a physical space like a factory, or an abstract scope such as a digital-service vertical. The result is purposeful, orchestrated networks in which interoperability and security are built into every connection, and dynamic relationships adapt in real time.

Orchestration

Central orchestration replaces conventional configuration. An orchestrator — sometimes called a broker — matches nodes with compatible context and CP roles, then instantiates direct, policy-governed relationships. No manual intervention, no static mapping.

This enables smarter automation, robust lifecycle management, and zero-trust enforcement, shifting connectivity from static schema to intent-based, policy-driven integration. Providers and consumers of CPs can change, scale, and update their profiles with minimal manual effort — streamlining integration for complex domains like smart buildings, IoT fleets, and enterprise services.

Open Source Implementation

The CNS/CP reference implementation is open source, and the architecture is designed to work across industries. The formal specification is published at github.com/CNSCP/specification; one specification and one namespace are what keep every implementation interoperable.

Project Arete

Project Arete is the open-source reference implementation of CNS/CP, focusing on real-world orchestration, CP management, and scalable workflow automation. It helps validate, extend, and support the adoption of CNS/CP standards.
